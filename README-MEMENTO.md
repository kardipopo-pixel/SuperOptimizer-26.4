# Memento

Полностью отдельный клиентский мод для Minecraft 26.4.

Memento превращает игру в личный архив воспоминаний: он замечает важные события и сохраняет скриншот вместе с координатами, измерением, биомом, миром и здоровьем.

F9 — открыть архив.
F10 — сделать ручной снимок.

Автоматические события: смена измерения, новый биом, опасное здоровье, дождь, гроза, большое путешествие, смерть.

Данные хранятся локально в config/memento/memories.
