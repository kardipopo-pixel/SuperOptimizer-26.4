# Rick's Portal Gun — Fabric 1.21.11

Фанатский портальный мод для Minecraft Java 1.21.11 Fabric.

ПКМ с пушкой — первый портал, ещё одна ПКМ — второй.
Shift + ПКМ — убрать свои порталы.
После установки двух порталов игрок телепортируется между ними в пределах одного измерения.

Внутри:
- собственная 3D-модель пушки в стиле C-137;
- процедурно сгенерированная зелёная переливающаяся портальная текстура;
- звуки создания/удаления портала и доставания пушки;
- анимация покачивания и выстрела в первом лице;
- русская локализация.

Модель собрана с нуля из элементов Minecraft по визуальным референсам.
