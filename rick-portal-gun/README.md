# Rick's Portal Gun — Fabric 1.21.11

Фанатский портальный мод для Minecraft Java 1.21.11 Fabric.

## Получение пушки в выживании
Когда Рик напишет в чат, выполни `/rick challenge`. Пройди паркур по зелёным платформам. Если упадёшь или не успеешь, курс исчезнет, блоки восстановятся, а испытание можно начать заново. После успеха Рик выдаст портальную пушку C-137.

## Управление
- **ПКМ** с пушкой — создать портал на блоке, на который смотришь.
- **ПКМ второй раз** — поставить парный портал. Перемещение работает между ними.
- **Shift + ПКМ** — убрать собственные порталы.
- **F8** с пушкой в руке — открыть настройки маршрута.
- В F8 можно выбрать парный режим либо телепортацию в координаты заданного измерения: Верхний мир, Незер или Энд. Нажми «Сохранить», чтобы отправить настройки серверу.

## Внутри
- переделанная 3D-модель с отдельным зелёным эмиттером, серым корпусом, тёмной рукоятью и экраном C-137;
- переливающаяся зелёная портальная текстура и звуки создания/удаления/доставания;
- анимация покачивания/выстрела в первом лице;
- русская локализация.

Для установки положи `rick-portal-gun-0.1.0.jar` в папку `.minecraft/mods`. Требуются Fabric Loader и Fabric API для Minecraft 1.21.11.
